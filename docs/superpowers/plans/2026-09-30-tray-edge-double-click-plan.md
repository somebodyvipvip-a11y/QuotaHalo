# 托盘双击原地展开边缘模式实施计划

## 1. 提取并测试托盘点击状态机

- 在 `src-tauri/src/main.rs` 中增加可单测的托盘点击状态，区分左键按下、松开和双击。
- 左键松开创建带代次的延迟单击；双击使代次失效并抑制下一次松开。
- Windows 从系统读取双击时间，其他平台使用默认值。
- 单元测试覆盖普通单击、双击取消、第二次松开抑制和后续单击恢复。

## 2. 保留托盘显示位置

- 将初次启动定位保留在 `setup`，托盘显示路径移除 `position_panel`。
- 托盘单击延迟完成后只显示／隐藏当前窗口，不改变位置或模式。
- 托盘双击立即显示并聚焦当前窗口，向前端发送双击动作事件。

## 3. 原地转换为完整模式

- 新增 Rust 命令：按当前边缘方向展开为完整模式。
- 完整来源恢复已保存物理尺寸；极简来源使用默认完整逻辑尺寸并按当前 DPI 转换。
- 复用现有边缘定位，恢复可缩放和圆角。
- 前端监听托盘双击事件；仅在存在边缘会话时调用命令，成功后切换完整 DOM、持久化 `full` 并清理边缘状态。

## 4. 回归、文档与发布

- 扩展前端生命周期测试，覆盖完整来源、极简来源、普通模式双击和失败时保留边缘状态。
- 更新 README 的托盘与边缘交互说明。
- 版本从 `0.5.1` 升级为 `0.6.0`，同步五处版本来源。
- 运行前端启动契约、JavaScript 语法检查、生命周期回归、Rust 测试、完整 Tauri 构建、版本一致性和 `git diff --check`。
- 审查最终差异并创建单一 `feat:` 提交。
