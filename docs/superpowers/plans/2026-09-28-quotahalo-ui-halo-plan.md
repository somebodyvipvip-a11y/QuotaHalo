# QuotaHalo Halo UI 改版实施计划

## 全局约束

- 仅修改界面；不得变更 Codex、WorkBuddy、TRAE、Qoder 的读取方式、刷新周期、凭据或托盘退出语义。
- 完整模式保留 330×515 固定窗口；极简模式继续使用现有窗口模式同步与本地存储键。
- 完整模式的关闭操作必须隐藏到托盘，不能退出进程。
- 顶栏显示实际 UTC 偏移（例如 `UTC+8`）；`Halo`、主圆环、进度和光晕共享当前主题色变量。
- 5 小时额度显示 SVG Halo 圆环、整数百分比、倒计时、`HH:mm 重置`；每周额度显示紧凑条形进度、整数百分比、`MM/DD HH:mm 重置`。
- 积分行固定为图标、名称、数值；更新时间仅显示在底栏。保留单服务失败原因、刷新状态、键盘焦点、Escape、拖动和减少动画支持。

## Task 1: 实现 Halo 主界面与窗口控制

修改 `src/index.html`、`src/main.js` 和 `src/styles.css`，将完整模式重组为已确认的方案一。

### 要求

1. 顶栏移除方形品牌底板，拆分 `Quota`/`Halo` 标题，并加入最小化、极简模式、关闭到托盘图标按钮。所有按钮有准确的 `aria-label` 与提示文本。
2. 用 SVG 圆环替换 5 小时卡片的线性主进度：环中央为整数剩余百分比，旁侧为倒计时与短重置时间；初始、错误和无数据状态不可显示伪造比例。
3. 每周卡片保留线性进度，改为紧凑层级；积分服务行移除各自更新时间，仅底栏显示全局更新时间。
4. 将时区文本改为 `UTC±H[:MM]` 形式；不要依赖中国时区硬编码。
5. 最小化使用 Tauri 当前窗口 API；关闭调用现有 `hide_panel` 命令；极简模式入口继续使用现有 `applyDisplayMode(true)`。
6. 极简模式使用同一个 Halo 圆环数据逻辑，只保留主额度、倒计时、短重置时间、恢复完整模式和关闭到托盘操作。
7. 样式复用现有主题变量、玻璃主题、设置面板、动画降级与拖动保护；低于或等于 10% 时在不改变数据文字的前提下应用警示状态。
8. 不新增依赖，不纳入任何未跟踪设计图片或 `.superpowers` 内容。

### 验证

- 执行 `npm run build`（若该命令只打包而不适合本机验证，至少执行对应的前端语法检查并报告原因）。
- 执行 `cargo check --manifest-path src-tauri/Cargo.toml`。
- 审查 `git diff --check`，并在报告中说明未启动完整 Tauri GUI 的原因（如有）。
