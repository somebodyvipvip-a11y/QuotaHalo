# 完整模式边缘窥视实施计划

## 1. 先扩展自动化测试

- 更新 `scripts/test-refresh-lifecycle.mjs` 的窗口与 Tauri 命令模拟，使边缘吸附返回方向和原始物理尺寸。
- 增加完整模式用例：启动时的程序性右下角定位不激活；用户从完整模式拖到边缘后收起；悬停恢复完整模式和原尺寸；离开后再次收起。
- 保留极简模式用例，验证其仍恢复固定极简尺寸。
- 覆盖边缘条拖动后按来源模式展开，以及用户拖动武装只消费一次。

## 2. 泛化前端边缘会话

- 在 `src/main.js` 中新增来源模式、原始尺寸和用户拖动武装状态。
- 将进入边缘模式的限制从“仅极简模式”改为“完整或极简模式均可”，调用吸附时保存后端返回的方向与尺寸。
- 悬停、离开和边缘条拖动时，把来源模式及保存尺寸传给原生命令；完整来源保持完整 DOM，极简来源保持极简 DOM。
- 仅在用户按下可拖动区域后处理 `onMoved` 防抖，完成一次判断后清除武装状态，从而排除启动定位、托盘定位、模式切换和内容自适应。
- 模式切换与边缘状态清理同时清除来源、尺寸、武装和计时器，防止旧会话泄漏。

## 3. 泛化 Rust 窗口尺寸恢复

- 在 `src-tauri/src/main.rs` 中为吸附结果增加可序列化结构，返回方向和收起前物理尺寸。
- 收起时沿用当前边缘条尺寸并禁用窗口缩放。
- 展开命令接收来源模式及原尺寸：极简模式使用固定 135×60 逻辑尺寸，完整模式恢复记录的物理尺寸；分别设置不可缩放或可缩放。
- 抽取可单测的展开尺寸选择逻辑，并补充完整模式自定义尺寸、极简固定尺寸及现有方向/位置回归测试。

## 4. 文档、版本与验证

- 更新 README，将“仅极简模式生效”改为完整与极简均支持，并说明按来源模式展开及启动不自动吸附。
- 将 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`、`src-tauri/tauri.conf.json` 的版本统一从 `0.4.7` 升至 `0.5.0`。
- 运行前端语法检查和生命周期脚本、`cargo fmt --check`、`cargo test`、`npm run build`、版本一致性检查及 `git diff --check`。
- 审查最终 diff，确保只包含本功能、文档和版本变化，并创建单一 `feat:` 提交。
