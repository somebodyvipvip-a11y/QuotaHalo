# 托盘模式菜单与点击行为调整实施计划

## 1. 补充窗口几何纯函数与 Rust 单元测试

- 在 `src-tauri/src/main.rs` 中先增加失败测试，覆盖最近的左、右、上边缘选择、距离相同优先级、多显示器负坐标和非零工作区原点。
- 增加普通模式切换后的工作区边界校正纯函数及测试，确保优先保留左上角，仅修正越界轴。
- 扩展边缘展开定位测试，覆盖左、右、上边缘锚定和沿边方向的范围限制。
- 实现纯函数并复用现有边缘尺寸与定位常量，避免建立第二套窗口几何规则。

## 2. 增加原地模式切换原生命令

- 调整现有 `set_widget_mode` 命令，使普通完整／极简切换在当前显示器工作区内完成边界校正。
- 新增 `snap_edge_peek_nearest` 命令：根据前端传入的来源模式，通过最近边缘纯函数决定方向，收缩并吸附窗口，返回方向和原始物理尺寸快照。
- 复用现有 `expand_edge_peek_to_full` 处理边缘到完整模式，复用 `expand_edge_peek` 的极简目标处理边缘到极简模式。
- 原生命令仅在全部必要信息取得并完成尺寸位置更新后返回成功，避免前端提交半完成状态。

## 3. 调整托盘菜单与点击分发

- 在 `src-tauri/src/main.rs` 创建完整模式、极简模式、边缘模式菜单项及分隔线，保留刷新、用量页面和退出项。
- 菜单模式项发送统一 `tray-mode-request` 事件，载荷分别为 `full`、`compact`、`edge`。
- 显式配置 `show_menu_on_left_click(false)`，使左键单击不弹出右键菜单，右键仍显示原生菜单。
- 保留现有托盘点击状态机：单击延迟后只原地显示／隐藏；双击取消单击并发送完整模式请求；完整模式下由前端判定为仅显示和聚焦。
- 新增前端可调用的 `reveal_panel` 命令；模式转换成功后再显示并聚焦，避免隐藏窗口切换时先显示错误尺寸。

## 4. 统一前端模式转换状态机

- 在 `src/main.js` 新增单一托盘模式请求处理函数，根据 `edgePeekDirection` 和 `document.body.dataset.mode` 判断当前状态。
- 完整模式请求：边缘模式沿当前边缘展开；普通极简模式原地放大；完整模式不调整几何。
- 极简模式请求：边缘模式沿当前边缘展开为极简尺寸；普通完整模式原地缩小；极简模式不调整几何。
- 边缘模式请求：普通模式调用主动吸附命令并保存来源模式、方向和展开尺寸；已在边缘模式时保持现状。
- 只有原生命令成功后才更新 DOM、清理或建立边缘状态并持久化 `full`／`compact`；失败时恢复原有边缘视觉状态。
- 双击事件复用完整模式请求处理函数，所有成功或无须转换的请求最后原地显示并聚焦。

## 5. 扩展回归测试和用户文档

- 保留并更新双击测试，验证极简和边缘进入完整模式、完整模式不触发尺寸调整，以及双击不会执行延迟单击。
