# 积分账户显示控制设计

## 目标

完整模式下，未登录的积分账户默认不显示。设置页提供四个可持久化的复选框：一个控制是否显示未登录账户，三个分别控制 WorkBuddy、TRAE、Qoder 是否显示。主窗口高度根据当前实际可见内容自动调整；极简模式维持固定的 135×60。

## 显示规则

- “显示未登录的积分账户”默认关闭。关闭时，仅已成功读取积分的账户可显示。
- WorkBuddy、TRAE、Qoder 三项默认开启。关闭某服务时，无论登录或额度读取状态如何，均隐藏其积分行。
- 已启用服务在读取中、登录成功或读取暂时失败时保持显示；只有可识别的未登录状态会被总开关隐藏。这样不会把网络错误误判为未登录而丢失诊断信息。
- 四个选项使用现有 `localStorage` 模式保存；设置变更即时生效。

## 高度同步

- 每次积分状态刷新、开关变更或进入/退出设置页时，前端依据主内容的实际高度请求同步完整窗口高度。
- 高度使用最小安全值，避免无积分行时压缩到无法阅读额度、底栏或设置内容的程度。
- 用户仍可自由调整窗口宽度；极简模式不触发完整模式高度同步。

## 验证与范围

- 前端测试覆盖默认值、单服务隐藏、未登录总开关和高度同步调用。
- 运行既有前端引导、刷新生命周期和 Rust 测试，以及 `git diff --check`。
- 不改动积分接口、凭据存储、额度计算、极简模式尺寸或皮肤机制。
