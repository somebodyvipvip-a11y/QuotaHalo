# QuotaHalo（额度光环）：设计说明

## 目标

构建一个 Windows 托盘小工具，点击托盘图标后在任务栏通知区域上方显示紧凑浮层。它从本机已经登录的 Codex App Server 读取真实额度，优先呈现 5 小时窗口的重置时间、剩余百分比和倒计时；下方呈现每周窗口的剩余百分比与重置时间。界面使用 Windows 本地时区，并明确标注时区。

首版以视觉效果和轻量化为优先：深色半透明面板、圆角、细边框、柔和阴影和青色强调色与参考图一致。不得硬编码额度时间或百分比。

## 技术选择

使用 Tauri 2：Rust 后端负责托盘、窗口生命周期、定位、App Server 进程和 JSON-RPC；HTML/CSS/TypeScript 前端负责显示和倒计时。

选择理由：Tauri 复用 Windows WebView2，避免携带 Chromium；CSS 能直接实现参考图中的圆角、半透明层、青色进度条及动效；Rust 提供小型原生宿主、系统托盘和进程控制。发布产物为一个 NSIS `.exe` 安装包，安装后运行一个主程序。

Windows 11 可使用系统背景材质增强；所有系统以 CSS 半透明深色层作为稳定的基础表现。Windows 10 若未安装 WebView2 Runtime，需要单独安装运行时；不将其并入安装包，以维持小体积。

## 组件与职责

### Rust 宿主

- 创建无边框、透明、始终置顶但默认隐藏的浮层窗口。
- 创建系统托盘图标：左键切换浮层；右键菜单提供“刷新额度”“打开 ChatGPT 用量页面”“退出”。
- 将浮层锚定到主显示器右下角任务栏通知区上方；无法取得精确工作区时，使用屏幕工作区右下角安全边距。
- 启动 `codex app-server --stdio` 并保持其标准输入/输出仅在内存中传输。
- 使用 JSON-RPC 顺序调用 `account/read` 与 `account/rateLimits/read`；解析响应和 `account/rateLimits/updated` 通知。
- 每 60 秒刷新一次，同时支持前端和托盘菜单手动刷新。窗口可见时每秒向前端更新倒计时所需的当前时间；无需频繁请求服务。
- 只将经解析的额度数值、状态和刷新时间发送给前端。不得读取、打印、写入或持久化认证令牌、账号邮箱或 App Server 原始数据。

### 额度归类与数据模型

- 首先使用 `rateLimitsByLimitId`；该字段不存在时回退至 `rateLimits`。从每个额度项的 `primary` 与 `secondary` 字段收集所有非空窗口，并按窗口字段值去重。
- 仅将 `windowDurationMins` 恰为 300 的窗口作为“5 小时额度”，恰为 10,080 的窗口作为“每周额度”。服务未返回精确窗口时显示对应的缺失状态，绝不按最接近的长度、时间或百分比推断。
- 每个 bucket 只保留 `usedPercent`、`windowDurationMins` 和 `resetsAt`。前端计算 `remainingPercent = clamp(100 - usedPercent, 0, 100)`。
- `resetsAt` 以秒为单位转换为本地时区时间；界面显示 IANA/Windows 时区映射后的标识，例如“北京时间 UTC+8”。倒计时从 `resetsAt - now` 计算，并在到点后显示“等待刷新”，直到下一次服务响应提供新值。

### 前端浮层

- 顶部：标题“额度时钟”和当前系统时区标签。
- 主区：5 小时额度名称、重置时刻、剩余百分比、反映剩余比例的进度条，以及“还剩 X 小时 X 分钟”。
- 次区：每周额度名称、剩余百分比和重置时刻。
- 底部：最近成功更新时间和刷新按钮。
- 失效状态：认证缺失、服务不可用、超时、未返回目标窗口和解析失败分别给出清晰说明；不显示占位时间或占位百分比；提供“打开 ChatGPT 用量页面”按钮。
- 点击窗外或按 Escape 隐藏浮层，不退出进程。

## App Server 协议与安全边界

应用只使用本机 `codex` 可执行文件和官方 App Server 的 JSONL 标准输入输出协议。启动后先发出：

1. `account/read`，参数 `{ "refreshToken": false }`，用于判断是否已有支持额度读取的登录会话。
2. `account/rateLimits/read`，用于读取服务实际返回的额度窗口。

遇到进程启动失败、无登录会话、API-key-only 会话、非成功 JSON-RPC 响应或超时，转为对应的失效状态。应用不启动登录、不注销、不刷新令牌，也不输出 App Server 的原始消息。官方接口字段和行为依据 [Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)。

“打开 ChatGPT 用量页面”使用系统浏览器访问 `https://chatgpt.com/#settings/Account`；该入口只在错误状态或用户从菜单主动选择时使用。

## 验证与交付

- Rust 单元测试：窗口归类、百分比边界、Unix 秒时间换算、倒计时及错误映射。
- 前端检查：有效数据、缺少 5 小时窗口、缺少周窗口、未登录和服务不可用状态。
- 手动验证：托盘点击、窗口锚定、窗外隐藏、手动刷新及实际 App Server 读取。测试过程不得打印认证数据。
- 提供 README，包含开发启动、构建单文件安装器、数据读取路径、WebView2 前提和已知限制。

## 范围边界

首版不包含自动开机启动、多账户切换、限额预警通知、额度重置操作、云端同步或任何认证流程。周窗口是否存在完全取决于 App Server 当次响应；不存在时只显示“服务未返回每周额度”。
