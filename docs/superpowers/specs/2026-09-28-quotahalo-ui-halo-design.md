# QuotaHalo 主界面 Halo 化改版设计

## 范围

将 QuotaHalo 完整模式调整为“主额度优先”布局，并补齐右上角窗口控制。保留现有的额度读取、积分读取、主题、透明度、托盘和设置能力；本次不改变任何服务接口、凭据存储或刷新周期。

## 视觉与布局

窗口继续维持无边框、透明玻璃风格和固定尺寸。完整模式自上而下分为：顶栏、Codex 5 小时主额度、每周额度、积分账户、底栏。

### 顶栏

- 品牌图形使用无方形底板的 Halo 圆环，描边与光晕由 `--accent` 和 `--accent-glow` 驱动。
- 标题拆为 `Quota` 与 `Halo` 两个文本节点；`Quota` 使用主文字色，`Halo` 使用当前主题色，主题切换时同步更新。
- 时区显示当前系统 UTC 偏移，例如 `UTC+8`，不再显示“北京时间”。系统不在东八区时仍显示实际偏移，避免错误标注。
- 右上角按“最小化、进入极简模式、关闭”排列，均为 Lucide 图标按钮，带可访问名称、悬停、焦点和禁用状态。
- “关闭”隐藏窗口至托盘而非终止进程；托盘菜单中的“退出”仍是唯一结束程序的入口。

### Codex 5 小时额度

- 主卡片以 SVG 环形进度显示剩余比例，环形轨道为低对比中性色，进度与光晕使用当前主题色。
- 圆环中央显示整数百分比；旁侧显示“距重置 X 小时 X 分”和短格式重置时间 `HH:mm 重置`。
- 保留语义化进度值和可读文本，颜色不作为唯一状态表达。
- 额度低于或等于 10% 时改用警示色，同时保留百分比文字；正常额度不使用服务专属颜色，保证 Halo 是唯一主视觉。

### Codex 每周额度

- 使用紧凑横向进度条，不再增加第二个大圆环。
- 显示“每周额度”、整数百分比和 `MM/DD HH:mm 重置`，不显示冗余倒计时。

### 积分账户与底栏

- WorkBuddy、TRAE、Qoder 行使用固定三列：服务图标、服务名称、积分值。
- 删除每行“更新于”副文本；无法读取时仅在该服务行显示简短原因，且不影响其他服务。
- 底栏显示一次全局“更新于 HH:mm”，保留刷新和设置按钮。
- 刷新期间按钮禁用并旋转；成功、失败和数据缺失沿用现有实际状态，不推算数据。

### 极简模式

- 仅显示 5 小时 Halo、剩余百分比、倒计时和短重置时间。
- 提供恢复完整模式与隐藏到托盘两个操作；极简模式也支持在非交互区域拖动。
- 通过现有 `quota-halo-display-mode` 本地存储键与 Tauri `set_widget_mode` 同步，兼容已有偏好。

## 实现边界

### 前端

- `src/index.html`：重组顶栏控制、完整模式额度标记与极简模式操作；内联图标继续采用现有 Lucide 路径风格。
- `src/main.js`：新增完整模式圆环更新逻辑、标题/时区渲染和窗口控制事件；保留现有额度、积分、设置与拖动流程。
- `src/styles.css`：将品牌、圆环、卡片和控制按钮抽为依赖现有主题变量的样式；补充窄窗口下不截断关键数据的规则。

### Tauri 窗口能力

- 最小化使用当前窗口 API；关闭复用后端的隐藏面板行为。
- 如现有后端命令不足，只新增最小的窗口命令，不触及额度服务、凭据和托盘退出行为。

## 状态与容错

- 读取中：圆环显示空轨道与“正在读取”，不使用陈旧比例伪装为实时数据。
- Codex 不可用：沿用现有错误区及打开用量页面能力；极简模式显示明确不可用说明。
- 单个积分服务不可用：服务行显示其真实失败原因，其余行和 Codex 卡片继续渲染。
- `prefers-reduced-motion` 下禁用旋转和进度过渡；键盘 Tab 可抵达全部控制项，Escape 的现有设置面板/隐藏行为不回归。

## 验证

1. 运行 `npm run dev`，检查完整模式、极简模式、主题切换、透明度、窗口拖动、最小化和关闭到托盘。
2. 检查 0%、10%、56%、95%、100% 额度下圆环与进度条的视觉和值一致性。
3. 验证 Codex 不可用、单项积分不可用、刷新中的文本与按钮状态。
4. 检查键盘焦点、Escape、减少动画偏好和窗口不发生裁切。
5. 在 Windows 打包前执行前端静态检查及 `cargo check --manifest-path src-tauri/Cargo.toml`；完成 UI 后人工截图比对确认。

## 非目标

- 不增加新的服务、额度口径、登录方式或数据轮询。
- 不改变托盘菜单的退出语义。
- 不将当前设计素材或脑暴预览文件纳入 Git。
