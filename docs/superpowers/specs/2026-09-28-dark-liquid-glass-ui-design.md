# QuotaHalo 深色 Liquid Glass UI 设计

## 目标

将 QuotaHalo 的完整、极简与设置界面统一为以深色模式为主的 Liquid Glass 视觉系统。界面保留现有额度数据、刷新、拖动、皮肤、透明度和显示模式行为；本次不改变数据读取或窗口生命周期。

## 视觉方向

基础画布使用石墨黑到深海军蓝的低对比渐变，并以两枚固定的蓝紫色环境光斑营造材质深度。主面板是深色半透明玻璃：低不透明度填充、背景模糊、细微白色高光边缘，以及不显脏的环境投影。颜色用于状态和焦点，而非填满整块界面。

系统蓝是默认强调色；其明度足以在深色玻璃上保持可读性。青绿和琥珀仅用于额度状态阈值，避免皮肤色覆盖所有文字和面板。现有皮肤选择保留，但改为改变环境光和强调色的色相，而不改变深色玻璃基础材质。

## 界面层级

完整模式的标题栏保持品牌与时区，但时区改为紧凑的磨砂胶囊。额度内容改为两张独立玻璃卡：五小时额度是主卡，拥有更大余量数字和更亮的进度轨；每周额度为更安静的次卡。卡片不再依赖中间的硬分隔线。底部操作图标加入悬浮玻璃反馈，设置面板像深色控制中心一样浮于底栏上方。

极简模式使用较窄的深色玻璃胶囊。圆环保留为主要识别元素，但使用双层轨道、柔和高光和系统蓝渐变；倒计时与重置时间分别形成主、次文字层级。错误状态沿用同一玻璃框架，并用清晰但不过量的警示色呈现动作按钮。

## 材质与可访问性

实现使用 `backdrop-filter: blur(...) saturate(...)`，同时提供不依赖背景模糊仍可辨认的半透明深色回退色。玻璃边界用低透明度白色而非高饱和描边。正文、次要文字、进度轨与交互状态均保持可读对比；焦点样式可见。减少动画偏好下关闭非必要过渡。

## 组件边界

CSS 以语义变量组织：基础画布、玻璃材质、文字层级、强调／状态色、阴影和圆角。完整面板、额度卡、进度条、工具按钮、设置浮层与极简胶囊分别拥有独立规则，避免 JavaScript 变动。JavaScript 只在现有主题和额度状态上附加必要的数据属性，以驱动状态颜色；不改变已存储的主题、透明度或显示模式键。

## 验证

在默认和全部六种环境光色下检查完整、极简、设置与错误状态。验证 60% 与 100% 窗口透明度、鼠标悬停／键盘焦点、刷新动画与缩放布局；同时确认无 `backdrop-filter` 环境中信息仍可读。运行现有前端启动检查与针对刷新生命周期的脚本，确保视觉改动未影响应用初始化。
