# 主窗口尺寸与缩放设计

## 目标

将 QuotaHalo 完整主窗口的默认尺寸改为 290×515 逻辑像素，并允许用户自由拖拽调整宽度和高度。极简模式继续使用固定的 135×60 逻辑像素，不向用户开放缩放。

## 方案

- Tauri 主窗口配置使用 290×515，且启动时可缩放。
- 完整模式与极简模式共用既有 `set_widget_mode` 命令：进入极简模式前记录窗口位置、将尺寸设为 135×60 并关闭缩放；返回完整模式时设为 290×515 并重新开启缩放，再恢复原位置。
- 不保存用户手动调整后的完整窗口尺寸；每次从极简模式返回都回到默认 290×515。这保持当前模式切换的确定性，避免新增持久化状态。

## 错误处理与验证

- 调整大小失败时继续返回现有中文错误信息；调整缩放状态失败时返回同类错误。
- 更新 Rust 逻辑尺寸单元测试，验证完整模式 290×515 和极简模式 135×60。
- 运行前端引导测试、刷新生命周期测试、Rust 测试和 `git diff --check`。

## 范围

仅改主窗口尺寸和可缩放状态。不会改动额度读取、皮肤、透明度、拖动、托盘行为或极简模式视觉布局。
