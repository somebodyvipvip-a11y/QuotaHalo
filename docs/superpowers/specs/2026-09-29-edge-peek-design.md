# 边缘窥视（Edge Peek）设计

## 目标

在极简模式中，窗口拖动至显示器左、右或上边缘时自动吸附并隐藏，仅保留 20 逻辑像素宽或高的额度进度条。鼠标悬停或拖动露出区域时恢复完整极简窗口。下边缘不参与吸附。

## 状态与交互

- 仅极简模式启用边缘窥视；完整模式、设置页及其可缩放行为保持不变。
- 松开拖动后的窗口若距左、右或上边缘不超过 12 逻辑像素，则进入对应边缘窥视状态；下边缘不触发。
- 左右边缘：窗口移出屏幕，仅露出宽 20 像素、高 60 像素的竖条。
- 上边缘：窗口移出屏幕，仅露出宽 135 像素、高 20 像素的横条。
- 指针悬停露出区域立即展开为 135×60 极简窗口；离开后用短延迟自动收起，避免边缘抖动。
- 按住露出区域拖动时先展开，再沿用当前窗口拖动；释放后重新检测吸附。

## 架构

- Rust 原生窗口事件处理显示器工作区、窗口位置和 DPI，完成跨显示器贴边判断、窗口定位与尺寸切换。
- 前端维护极简、边缘窥视和已展开状态，渲染横向或纵向的 5 小时额度进度条，并通过 Tauri 命令请求原生窗口状态变更。
- 进度条沿用现有主题颜色和剩余额度数据；边缘窥视不触发新的额度请求。

## 错误处理与验证

- 获取显示器或窗口位置失败时保持普通极简模式，不隐藏窗口。
- 进入完整模式、关闭到托盘或切换主题时清除边缘窥视状态与延迟计时器。
- 为方向选择、尺寸和窗口位置计算添加 Rust 单元测试；前端测试覆盖悬停展开、离开收起、拖动展开及下边缘不吸附。
- 运行前端引导、刷新生命周期、Rust 测试和 `git diff --check`。
