# QuotaHalo 实体皮肤设计

## 目标

将现有六套半透明玻璃主题收敛为参考图的四套实体皮肤：紫晶、湛蓝、青绿、琥珀。透明度只由现有窗口不透明度设置统一控制。

## 皮肤

| 标识 | 名称 | 主色 | 表面方向 |
| --- | --- | --- | --- |
| `violet` | 紫晶 | 紫红到紫 | 深靛蓝面板 |
| `blue` | 湛蓝 | 亮蓝到青蓝 | 深蓝面板 |
| `mint` | 青绿 | 薄荷青绿 | 深青面板 |
| `amber` | 琥珀 | 金黄 | 暖深灰面板 |

每套皮肤定义同一组不透明颜色令牌：窗口表面、卡片表面、控件表面、轨道、边框、文字、主色、强调色与光晕色。Halo 标题、圆环、进度条、品牌环和重点控件使用该主题的主色或强调色。

## 透明度与玻璃

- 移除卡片、控件、设置面板和环境光中的 `rgba()` 半透明叠层，移除 `backdrop-filter` 与 `-webkit-backdrop-filter`。
- 面板及内部表面均使用不透明色或不透明渐变。
- 保留设置中的 60%–100% 窗口不透明度滑块；它通过现有 Tauri `set_window_opacity` 对整个窗口统一生效。
- 100% 时界面完全实体；低于 100% 时系统窗口透明度是唯一透明来源。

## 设置交互

- 外观区显示一项“皮肤”折叠按钮，显示当前皮肤名称及展开状态。
- 点击按钮展开四项 2×2 皮肤选择；再次点击可收起。
- 选择皮肤后应用主题、写入既有 `quota-halo-skin` 本地存储键，并自动收起选择区。
- 旧主题值 `cyan`、`indigo`、`moss`、`mono` 自动回退到 `violet`，不保留旧皮肤入口。

## 主窗口文案

删除 5 小时额度卡片上的“主额度”徽标，只保留“Codex · 5 小时额度”。

## 范围与验证

- 仅修改 `src/index.html`、`src/main.js`、`src/styles.css`；不改额度、积分、登录、代理、Tauri 窗口不透明度命令或刷新逻辑。
- 验证四种皮肤、折叠/展开、选择后自动收起、旧主题回退、透明度滑块、完整/极简模式和键盘焦点。
- 运行 `node --check src/main.js`、`npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml` 与 `git diff --check`。
