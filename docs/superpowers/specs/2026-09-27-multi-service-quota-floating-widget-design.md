# 多服务额度悬浮窗设计

## 目标

将 Codex、Qoder、Trae 和 Workbuddy 的剩余额度汇总为一个类似系统流量监控的极简桌面悬浮窗。

## 视觉与尺寸

- 约 300 × 155 px，深色半透明玻璃质感，圆角和轻微阴影。
- 位于桌面右侧并留出外边距；不包含任务栏、时间、刷新、关闭或其他操作控件。
- 使用白色主文字、灰色辅助分隔线与青色强调色；仅在低额度时使用暖色提醒。

## 信息布局

- 顶部：`额度监控` 和一个小型状态点。
- 内容：四条纵向紧凑列表，左侧为服务名，右侧为额度。
- Codex：显示 `97%`，其下带一条青色细进度条。
- Qoder：显示 `1,280 积分`，不显示百分比或进度条。
- Trae：显示 `860 积分`，不显示百分比或进度条。
- Workbuddy：显示 `2,450 积分`，不显示百分比或进度条。

## 状态与边界

- 正常额度保持白字和青色 Codex 进度条。
- 低额度时，只将对应数值/状态提示改为暖色；不添加冗余弹窗或图形。
- 设计稿使用示例积分，实际接入时可替换为实时数据。

## 验收标准

- 一眼可分辨四个服务及其单位。
- Codex 明确以百分比显示，其他三项明确以积分显示。
- 整体小于此前的单服务面板，信息密度接近流量悬浮窗。
