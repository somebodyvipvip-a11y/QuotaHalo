# QuotaHalo 紧凑圆角与刷新展示设计

## 目标

在不改变额度读取、窗口尺寸和现有四套皮肤的前提下，降低外框圆角与 5 小时额度区域的视觉占比，并让已有数据在后台刷新期间保持可读。

## 视觉调整

- 主窗口 `.panel` 的外框圆角由 24px 统一降为 16px；极简模式复用同一外框，因此同步生效。
- 保留卡片、按钮和设置面板的现有圆角，避免所有元素同时变硬；这限定为方案 A 的最小视觉调整。
- 5 小时 Halo 圆环由 116px 缩至 104px，并相应压缩与详情列的间距，主卡不增加高度。
- 详情区采用固定三层：`距离重置还剩`、倒计时、`HH:mm 重置`。首行由 10px 增至 11px；倒计时和重置时间的现有层级保持。
- 极简模式的外框圆角同样为 16px，不额外改变其内部圆环尺寸或控件圆角。

## 皮肤色卡

- 四个皮肤选择色卡使用固定值，不读取当前主题的 `--accent` 等变量。
- 紫晶固定为紫色；湛蓝、青绿、琥珀维持各自的固定蓝、薄荷、金黄色。
- 切换皮肤只改变活动态与应用主题，不得改变任何未选中色卡的颜色。

## 刷新展示

- 首次加载（尚没有有效额度快照）保留“正在读取”加载文案与现有 loading 状态。
- 已有有效额度快照时，手动刷新、定时刷新和服务刷新不得将主界面或极简模式替换为“正在读取”；旧数值和倒计时保持显示。
- 新响应到达后直接以新快照重绘前台数值。
- 保留现有超时规则：超时仍显示上次数值，并显示“读取超时”提示；无有效快照的其他错误仍按既有不可用状态呈现。

## 范围与验证

- 修改范围：`src/index.html`、`src/main.js`、`src/styles.css` 和版本元数据。
- 不修改 Tauri 窗口尺寸、额度请求、代理、积分服务接口或不透明度机制。
- 发布版本从 `0.1.23` 升至 `0.1.24`。
- 验证 PowerShell/Node 前端语法、首次加载、已有数据刷新、超时、四套皮肤色卡、完整与极简模式、版本一致性及 `git diff --check`。若 Rust 构建继续受 crates.io 网络阻断，应记录为环境问题，不改锁定依赖。
