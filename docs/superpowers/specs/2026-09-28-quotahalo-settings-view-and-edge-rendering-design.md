# QuotaHalo 设置独立视图与边缘渲染设计

## 目标

解决透明 Tauri 浮层外缘出现可见细线、圆角不连续的问题，并将设置从覆盖主界面的窄浮层改为占满完整窗口内容区的独立视图。保留 330×515 完整模式窗口、135×60 极简模式、额度读取和现有六套皮肤。

## 已确认的根因

- `.panel` 直接绘制了 1px 的 `var(--border)` 外框，这就是截图中的紫色外边线。
- 窗口使用透明客户区，Windows 原生 `SetWindowRgn` 裁切和 WebView 内部 CSS 圆角分别参与最终轮廓。两个半径或逻辑/物理像素换算不一致时，半透明边缘像素会在高 DPI 下显出锯齿或细缝。

## 方案

### 外缘与圆角

- 建立唯一的完整模式圆角常量，CSS `.panel` 与 Windows `CreateRoundRectRgn` 使用同一个视觉半径；原生侧按窗口实际物理尺寸/DPI 换算圆角直径。
- 移除 `.panel` 的可见外描边和外投影，不再将皮肤强调色画在窗口边界。
- 保留裁切内侧的一层低对比度高光，作为表面层次而非外框；`overflow: hidden` 继续裁切页面内容。
- 极简模式沿用同一原生与 CSS 半径策略，避免两种模式切换后出现不同轮廓。

### 双视图切换

- 在同一窗口中保留概览视图与新增设置视图；两者互斥显示，不创建原生子窗口，也不调整窗口尺寸。
- 齿轮按钮进入设置视图。设置页顶部提供返回按钮和“设置”标题；Esc 在设置页返回概览，在概览页维持现有隐藏窗口行为。
- 完整模式底栏继续保留更新时间与刷新。设置页使用相同底栏，刷新在设置中仍可刷新服务状态。
- 极简模式隐藏完整设置视图；从极简模式恢复完整模式后返回概览。

### 设置页排版

- 设置正文采用可滚动单列，两张清晰的分组卡片：`连接服务` 与 `外观`。
- Qoder 和 TRAE 采用一致的服务项：服务名称与状态同一行，说明文字在其下，凭据输入和主要操作在下一行；已连接时“忘记登录”成为次级危险操作。
- TRAE 的“打开网页登录窗口”和“手动粘贴 Cloud-IDE-Token”明确分为两种方式，以分隔文案消除歧义。
- 成功、失败和处理中消息显示在对应服务项内；连接期间按钮禁用，避免重复提交。现有后端命令和 Windows 凭据保存方式不变。
- 外观卡片包含紧凑固定色彩的皮肤网格，以及单独的透明度行（数值、滑杆）。控件间距、标签字重和按钮高度统一。

## 状态与错误处理

- `settingsView` 只管理前端显示状态；不会持久化，也不会改变额度快照或连接凭据。
- `renderConnectionStatus` 继续作为连接状态的单一来源，并把状态同步到概览额度行和设置中的服务项。
- 连接请求开始时只禁用该服务的操作控件；无论成功还是失败均恢复可用状态，并在对应服务项展示结果。
- 维持现有首次加载、旧额度保留、刷新超时和服务单项失败的呈现逻辑。
